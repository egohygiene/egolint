## Implementation boundaries

- [Adaptive capabilities](adaptive-capabilities.md) compose the existing pinned
  MegaLinter catalog/matrix with native and complementary inventories. Plans and
  reports explain admitted selections and skips; configuration-only tools are
  not arbitrary executors. File/manifest discovery is bounded and shell-free.
- [Enforcement](enforcement.md) preserves underlying run status and execution
  failures. Ratchet evidence binds source, repository, policy, actual tool/native
  executable identity and review/expiry metadata, with a separately reviewed
  checksum. Fix preview/apply remains independent.
- [Structural policy](ast-grep-evaluation.md) adapts ast-grep 0.51.1 as an opt-in
  host runtime. Four embedded rules cover JavaScript, TypeScript, Python and
  Rust. Findings are advisory and normalized without source snippets.
- Config, plan and report schemas are regenerated; registry, decision, baseline
  and enforcement schemas are added. Existing closed-schema consumers need the
  matching new schemas before reading new output. Contract version remains 1.
- No dependency or lockfile changes, full-image tool installation, workflow
  changes or historical audit edits. The lightweight Docker builder copies the
  additional embedded inputs required for a source build.
